# ASE-Portfolio-Comia

## 1. Course Introduction
CPELX230-330 explores the intersection of modern software engineering methodologies, version control workflows, and autonomous AI systems. The course focuses on transitioning from traditional deterministic programming to designing, governing, and deploying AI-driven agentic applications responsibly.

## 2. Personal Learning Goals
* Master collaborative Git/GitHub workflows and Agile sprint practices for AI-integrated software projects.
* Understand how to architect reliable, goal-driven AI agents while mitigating security vulnerabilities such as prompt injection and unauthorized tool execution.
* Apply risk management frameworks to ensure safety, privacy, and human oversight in automated systems.

## 3. Reflection from Part A 
Transitioning from traditional software to Agentic Software Engineering shifts the developer's role from writing explicit rule-based logic to orchestrating autonomous, goal-directed agents. While AI agents accelerate development through dynamic planning and tool use, their probabilistic nature introduces risks like hallucinations and security exploits. Pairing iterative Agile methodologies with strict human-in-the-loop oversight ensures that agentic systems remain adaptable, secure, and aligned with human intent.
